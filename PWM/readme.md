## Implementing Three-Phase Sinusoidal Signal Transformations

#### Overview

This module handles the generation of three-phase sinusoidal references $\tilde{u}^*_{\text{a,b,c}}(t)$ required by the PWM submodule. The scalar amplitude $\hat{u}^*(f_1)$ generated by the $U/f$-generation block is mapped into the three-phase time domain using a two-step coordinate transformation process.

#### Step 1: Inverse Park Transformation (dq $\rightarrow$ $\alpha\beta$)

The $U/f$-amplitude $\hat{u}^*(f_1)$ defines the magnitude of the rotating voltage vector in the synchronously rotating dq-frame. For pure voltage-amplitude control, the reference vector is aligned with the d-axis:

* $u^*_{\text{d}} = \hat{u}^*(f_1)$
* $u^*_{\text{q}} = 0$

The electrical angle is integrated from the output of the frequency block:


$$\varepsilon_{\text{el}}(t) = 2\pi \int_{0}^{t} f_1(\tau) \text{d}\tau$$

The inverse Park transformation then maps the dq-components into the stationary $\alpha\beta$-frame using the electrical angle:

## Output Behavior

The resulting signals $\tilde{u}^*_{\text{a,b,c}}(t)$ are purely sinusoidal and mutually displaced by 120°. They maintain a peak value equal to $\hat{u}^*(f_1)$ and are passed directly to the PWM submodule as normalized voltage references.
